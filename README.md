## 📌 Project Overview

This project uses:

- 📚 Study Hours as input feature
- 📝 Student Marks as target output

👉 Objective: Predict student marks based on the number of study hours using Linear Regression.

The model learns the relationship between study hours and marks, then predicts marks for new input values.

## 📌 Linear Regression Formula

The project uses the Linear Regression equation:

```math
y = mx + b
```

Where:
- `y` = Predicted marks
- `x` = Study hours
- `m` = Slope/Coefficient
- `b` = Intercept
